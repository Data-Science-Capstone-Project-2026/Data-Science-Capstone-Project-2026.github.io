# Willamette Applicant Trajectory — Project Site

This repository hosts the public-facing website for our DATA 510 capstone project,
**Willamette Applicant Trajectory: Predicting Student College Enrollment Destination**.

The site covers:

- **Home** — project abstract, problem statement, and stakeholder impact
- **Data** — data sources, how they were combined, and how student privacy was protected
- **Analysis** — the methods used to group applicants and predict enrollment destination
- **Findings** — key results and what they mean for Admissions outreach
- **Deliverables** - final writeup and poster, available to download

Built with [Quarto](https://quarto.org/). For the full analysis code, data
pipeline, and modeling scripts, see our main project repository:
[Willamette Applicant Trajectory - Capstone2026](https://github.com/Data-Science-Capstone-Project-2026/Public_Repository).

Note: the underlying applicant data is confidential and is not included in
the public repository.
